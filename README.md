# Time Greeting — kayralrics.net

A lightweight, responsive greeting website with a pure black background and large red text. The greeting and clock use the visitor's device-local time and update automatically. No installation, API, build step, or internet connection is required to run the page (except when opening the credit link).

## Run

Open `index.html` in any modern web browser.

## Greeting schedule

- **Good Morning:** 5:00 AM–11:59 AM
- **Good Afternoon:** 12:00 PM–4:59 PM
- **Good Evening:** 5:00 PM–8:59 PM
- **Good Night:** 9:00 PM–4:59 AM

The schedule uses the browser's local time. “Good night” is traditionally most often used when saying goodbye or going to bed rather than as an arrival greeting, but it is included for the nighttime period as requested.
